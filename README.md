`concerthq/signet-standard`, recorded automatically by the CLA Assistant workflow
(`.github/workflows/cla.yml` on `main`). Do not edit `signatures/version1/cla.json`
by hand. The CLA contributors agree to is [`CLA.md`](https://github.com/concerthq/signet-standard/blob/main/CLA.md).
